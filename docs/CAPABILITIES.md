# Backend capabilities

Generated by `build/test_backend_tiers . --markdown` from `inc/engine/backend/tier_table.inc`; do not edit by hand.

- **Portable**: a Slang kernel exists; the CUDA build keeps its tuned kernel, CPU and Vulkan use the Slang one.
- **PortablePending**: elementwise or reduction work with a plain reference on CPU and no Slang kernel yet.
- **CudaSm70**: hand-tuned CUDA/SM70; other backends get a stub that aborts unless the note names a reference.
