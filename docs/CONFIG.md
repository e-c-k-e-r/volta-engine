# Configuration

Generated by `volta_server --print-config-docs`; do not edit by hand (the static gate checks that this file is current).

A launch is configured by a JSON file (`--config file.json`) and command-line flags; flags win over the file, the file wins
over environment variables, environment variables win over built-in defaults. Unknown keys, unknown options and invalid
values are fatal errors. The model type is never configured: it is read from the checkpoint's `config.json`.

## Launch config keys (top level of the JSON file)

| Key | CLI flag | Default | Description |
|---|---|---|---|
| `model_dir` | `--model-dir` | required | checkpoint directory |
| `draft_model_dir` | `--draft-model-dir` | none | DFlash2 drafter checkpoint; required with `use_speculation` |
| `use_speculation` | `--speculative` | false | enable speculative decoding |
| `tp_size` | `--tp-size` | 4 | GPUs (1, 2 or 4; GLM runs on 1 or 4) |
| `host`, `port` | `--host`, `--port` | 0.0.0.0, 8000 | listen address |
| `max_batch_size` | `--max-batch-size` | 8 | concurrent decode slots the scheduler may fill (capped by `max_slots`) |
| `default_max_tokens` | `--max-tokens` | 256 | `max_tokens` for requests that omit it |
| `default_temperature`, `default_top_p`, `default_top_k` | `--temperature` | from the checkpoint's `generation_config.json` | sampling defaults for requests that omit them |
| `default_enable_thinking` | | false | thinking on for requests that do not say |
| `request_timeout_s` | | 30 | seconds a connection may stay silent before its request is complete |
| `options` | `--set key=value` | | the options below |

## Options

Every option can be set in the launch config's `options` object, with `--set key=value`, or through the environment variable
shown. Debug options use `ENGINE_DEBUG_<NAME>`. Test-only variables are listed at the end.

| Option | Type | Default | Environment | Description |
|---|---|---|---|---|
| `log_level` | string | `info` | `ENGINE_LOG_LEVEL` | log threshold: error, warn, info or debug |
| `tp` | int | `-1` | `ENGINE_TP` | rank count: 1, 2 or 4 (GLM: 1 or 4); <0 uses the launch's tp_size |
| `arena_gib` | int | `-1` | `ENGINE_ARENA_GIB` | per-GPU arena in GiB; <=0 sizes it from the device's free memory minus vram_reserve_mib |
| `vram_reserve_mib` | int | `-1` | `ENGINE_VRAM_RESERVE_MIB` | memory left outside the arena for graphs, workspaces and the CUDA context; <0 uses the model's default (Qwen 1536, GLM 288) |
| `max_seq` | int | `0` | `ENGINE_MAX_SEQ` | context window per slot in tokens (sizes the KV pool); 0 = the model default (Qwen 32768, GLM 12288) |
| `max_slots` | int | `0` | `ENGINE_MAX_SLOTS` | decode slots; 0 = the model default (Qwen 8, GLM 1) |
| `prefix_cache_gib` | int | `16` | `ENGINE_PREFIX_CACHE_GIB` | pinned host RAM for the prefix cache (sequence snapshots); 0 = off |
| `prefill_chunk` | int | `256` | `ENGINE_PREFILL_CHUNK` | prompt tokens a new request prefills per scheduler step while other requests are decoding (decode steps run between the pieces); 0 = the whole prompt at once |
| `prefix_interval` | int | `16384` | `ENGINE_PREFIX_INTERVAL` | prompt tokens between automatic prefix checkpoints inside long prompts; 0 = only the requested ones |
| `kv_format` | string | `(empty)` | `ENGINE_KV_FORMAT` | KV cache format: fp16, fp8, k8v4 or nvfp4; empty = the model default (fp16). GLM stores its single latent tensor in one format (k8v4 = 8-bit) |
| `expert_cache` | float | `1` | `ENGINE_EXPERT_CACHE` | GLM resident routed-expert fraction in (0, 1]; below 1 enables the two-tier expert cache |
| `expert_adapt_every` | int | `64` | `ENGINE_EXPERT_ADAPT_EVERY` | decode steps between expert residency rebalances (0 = never) |
| `expert_swaps` | int | `-1` | `ENGINE_EXPERT_SWAPS` | maximum expert swaps per rebalance; <0 = the tier default |
| `speculator` | string | `dflash` | `ENGINE_SPECULATOR` | speculation source: dflash (needs a draft model) or mtp (the checkpoint's own multi-token-prediction head, Qwen) |
| `mtp_depth` | int | `7` | `ENGINE_MTP_DEPTH` | most draft tokens per round with speculator=mtp (1 to 7); the head stops chaining earlier when its recent accuracy is low |
| `draft_tp` | bool | `true` | `ENGINE_DRAFT_TP` | false runs the drafter on rank 0 only |
| `dsa` | bool | `true` | `ENGINE_DSA` | GLM sparse attention indexer (top-2048 key selection); false attends densely |
| `max_image_tokens` | int | `1024` | `ENGINE_MAX_IMAGE_TOKENS` | largest image the vision tower accepts, in language-model tokens (4 patches each; sizes its scratch and caps the resize); 0 = image input off |
| `expert_stats` | bool | `true` | `ENGINE_EXPERT_STATS` | count the routes per expert for the monitor page (a device sync per rank about once a second while serving) |
| `spec_ctrl` | bool | `true` | `ENGINE_SPEC_CTRL` | adaptive speculation controller; false always speculates |
| **Debug** | | | | |
| `expert_log` | bool | `false` | `ENGINE_DEBUG_EXPERT_LOG` | per-rebalance expert tier statistics |
| `dsa_diag` | bool | `false` | `ENGINE_DEBUG_DSA_DIAG` | sparse-attention indexer diagnostics |
| `trace_layers` | string | `(empty)` | `ENGINE_DEBUG_TRACE_LAYERS` | GLM: file that receives the last row's residual streams after every layer of every eager forward (rank 0) |
| `perturb_embed` | float | `0` | `ENGINE_DEBUG_PERTURB_EMBED` | GLM: multiply every prompt embedding element by 1 + eps * u (u in [-1, 1], hashed from position and dimension, so independent of chunking); eager prefill only, a noise-floor probe |
| `route_replay` | string | `(empty)` | `ENGINE_DEBUG_ROUTE_REPLAY` | GLM: a <trace_layers>.route file; eager prefill rows found in it use the recorded expert ids and weights (the latest record per layer and position wins), isolating router flips |
| `qwen4_halt` | int | `-1` | `ENGINE_DEBUG_QWEN4_HALT` | qwen4_exp bring-up: stop the layer stack after this many sublayer sites (0 = after layer 0's attention half, 1 = after its MLP half, ...); <0 runs everything |
| `qsa_off` | bool | `false` | `ENGINE_DEBUG_QSA_OFF` | qwen4_exp: attend densely past the QSA budget (A/B against the sparse selection) |
| `teacher_streams` | string | `(empty)` | `ENGINE_DEBUG_TEACHER_STREAMS` | qwen4_exp: file of reference residual streams per layer input (int rows header, then [47][rows][4][hidden] fp32): every layer from 1 on starts from the reference's streams, isolating the per-layer error |
| `router_fp16` | bool | `false` | `ENGINE_DEBUG_ROUTER_FP16` | qwen4_exp: round the router logits to fp16 before the top-k, as the exllamav3 router stores them |
| `perturb_layers` | float | `0` | `ENGINE_DEBUG_PERTURB_LAYERS` | qwen4_exp: multiply the residual streams after every layer by 1 + eps * u (u hashed from position, stream, dim and layer): a model of per-layer rounding noise; eager prefill only |
| `spec_ctrl_log` | bool | `false` | `ENGINE_DEBUG_SPEC_CTRL_LOG` | speculation controller decisions |
| `spec_joint` | bool | `false` | `ENGINE_DEBUG_SPEC_JOINT` | per-slot speculators (MTP): one draft chain and one verify forward for the blocks of all speculating slots (measured: no gain over one slot per round at 2 requests, up to ~+6-25% at 4; outputs then differ from a lone request); false runs one slot per round |
| `spec_interleave` | bool | `true` | `ENGINE_DEBUG_SPEC_INTERLEAVE` | speculators with a context per slot (MTP): interleave one slot's round per step; false steps all active slots plainly together while more than one decodes (A/B) |
| `no_graphs` | bool | `false` | `ENGINE_DEBUG_NO_GRAPHS` | eager execution, no CUDA graphs |
| `dump_requests` | string | `(empty)` | `ENGINE_DEBUG_DUMP_REQUESTS` | directory: write every API request body and rendered prompt there |
| `dump_draft_round` | int | `-1` | `ENGINE_DEBUG_DUMP_DRAFT_ROUND` | speculation round whose drafter inputs are written to /tmp/draft_dump.bin; <0 = off |

## Test and tool variables

| Variable | Description |
|---|---|
| `ENGINE_MODEL_ROOT` | directory holding the checkpoints used by tests and benches (also read from `tests/local.env`) |
| `ENGINE_TEST_QWEN_DIR`, `ENGINE_TEST_DRAFT_DIR`, `ENGINE_TEST_GLM_DIR`, `ENGINE_TEST_GLM_DRAFT_DIR` | override one checkpoint |
| `ENGINE_CPU_THREADS` | worker threads of the CPU backend (default: the process's allowed cores) |
| `ENGINE_DEBUG_CPU_TRACE` | per-call timing lines in the CPU backend |
| `ENGINE_VK_DEVICE` | Vulkan device index |
| `ENGINE_SPV_DIR` | directory of compiled SPIR-V modules (default: the build directory) |
| `BENCH_*`, `AR_ROWS`, `MOE_ROWS`, `MOE_ACTIVE`, `MLA_TIME`, `SPEC_STATE_MODEL` | inputs of individual benches and parity tests (see the test source) |
